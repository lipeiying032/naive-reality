naivereal kernel: official naiveproxy + REALITY (BoringSSL patches)

Usage:
  naive [--log] config.json

config.json is the official naive client format plus an optional
"reality" block (or equivalent flat keys):
  reality.server_name        SNI presented to the REALITY server (the
                             camouflage target hostname)
  reality.public_key         server static X25519 public key, base64url
                             (32 bytes; generated by: naivereal-frontend genkey)
  reality.short_id           short id, at most 16 hex chars
  --reality-server-name=HOST
  --reality-public-key=KEY   command-line equivalents of the above
  --reality-short-id=HEX

Without the reality block the kernel behaves exactly like the official
naiveproxy client.

v2rayN: replace <v2rayN>\bin\naiveproxy\naive.exe with this build;
a profile is any official naive config.json. See docs/v2rayN.md.
